# rongo — a fair test of the Indus / rongorongo resemblance

Investigation 01 of Deep Memory. Merged into `ejhong/birdmen` on 10 September 2026 from its own
repository, `github.com/ejhong/rongo`, now archived; the history came with it. Paths below are
relative to the Deep Memory repository root, and the page is served at
<https://ejhong.github.io/birdmen/rongo/>.

Do the Indus script and Easter Island's rongorongo share more sign shapes than two
unrelated scripts do? This repository digitises both complete sign inventories from
the standard catalogues, renders twenty-two control scripts from fonts, reduces every
sign to a common skeleton representation, and scores every script pair the same way.
The results are published at **https://ejhong.github.io/birdmen/rongo/** with every step shown.

Short version: measured against the full catalogues rather than the famous hand-drawn
chart, the pair is ordinary. Indus's apparent edge as rongorongo's closest partner
disappears once the font controls are given hand-drawn wobble, and the chart's 24
pairs mostly owe their punch to the redrawing.

## Layout

```
inputs/rongo/           the tweet screenshots and the two research briefs that started this
data/rongo/raw/         scans (Mahadevan 1977 sign list; Barthel 1958 Formentafeln) and the Noto fonts
data/rongo/glyphs/      one PNG per sign, per script, plus manifests with provenance of every crop
data/rongo/norm/        64x64 skeleton of every sign, plus complexity counts
data/rongo/features/    chamfer / HOG / DINOv2 features per script (regenerated by features.py; not committed)
data/rongo/qa/          overlays and contact sheets used to check the extraction by eye
data/rongo/results/     results.json (all statistics), wobble.json, threshold.json
data/rongo/fidelity/    the 24 chart pairs: cells, automatic candidates, reviewer mapping, scores
pipeline/rongo/         the code, in run order (see below)
docs/rongo/             the static site (GitHub Pages) (data/site.json + images are generated by build_site.py)
```

## Run it

```
python -m venv .venv && . .venv/bin/activate
pip install -r pipeline/rongo/requirements.txt
brew install tesseract                     # OCR check of catalogue numbers (macOS; apt install tesseract-ocr elsewhere)

python pipeline/rongo/extract_barthel.py         # 8 plates  -> data/glyphs/rongorongo/
python pipeline/rongo/extract_mahadevan.py       # 4 pages   -> data/glyphs/indus/
python pipeline/rongo/render_fonts.py            # 22 fonts  -> data/glyphs/<script>/
python pipeline/rongo/normalize.py indus rongorongo egyptian anatolian linear_a linear_b cypro_minoan cuneiform ugaritic old_persian phoenician old_italic carian lycian old_south_arabian meroitic runic old_turkic tifinagh vai mende_kikakui pahawh_hmong nushu yi
python pipeline/rongo/features.py  <same list>   # downloads DINOv2 ViT-S/14 weights on first run
python pipeline/rongo/wobble.py    egyptian anatolian linear_a linear_b cuneiform vai mende_kikakui nushu yi
python pipeline/rongo/features.py  egyptian_w anatolian_w linear_a_w linear_b_w cuneiform_w vai_w mende_kikakui_w nushu_w yi_w
cd pipeline/rongo && python experiments.py && python -c "import experiments as E; E.wobble_block()" && cd ..
cd pipeline/rongo && python fidelity.py && python fidelity_stats.py && cd ..
python pipeline/rongo/validate_metric.py       # metric sanity check: retrieve each glyph from an independent low-res rendition
python pipeline/rongo/build_site.py
```

Everything is seeded. The one manual step is `data/rongo/fidelity/mapping.json`, the reviewer's
identification of the 24 chart drawings; the automatic candidates are kept next to it.
